# Guía de marca Urbanlytics

## Nombre
Urbanlytics

## Logo
Usar los archivos existentes:
- `frontend/public/assets/img/logo-placeholder.svg`
- `frontend/public/assets/img/logo-mark.svg`

## Colores
- Azul principal: `#1551a1`
- Azul profundo: `#123e7a`
- Azul acción: `#0d6efd`
- Fondo claro: `#f4f8fc`
- Texto: `#14263a`
- Riesgo alto: `#a31f34`
- Riesgo medio: `#b85c00`
- Riesgo bajo: `#237843`

## Tipografía
Fuente base del sistema: `Trebuchet MS`, `Segoe UI`, sans-serif. Usar pesos fuertes para KPIs y encabezados, texto regular para descripciones.

## Componentes
- Tarjetas con radio máximo de 8px en nuevas superficies.
- Badges para estado, clima y riesgo.
- Mapa y gráfico como elementos principales del dashboard.
- Colores de riesgo consistentes entre mapa, alertas y documentación.

## Tono visual
Interfaz operativa, clara y orientada a toma de decisiones. Evitar decoración innecesaria y priorizar lectura rápida de mapa, filtros y alertas.
