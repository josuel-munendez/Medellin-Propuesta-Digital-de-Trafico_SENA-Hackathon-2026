# Manual de usuario

1. Abre el frontend en el navegador y espera a que cargue el mapa.
2. Ajusta el filtro horario para ver accidentes entre dos horas específicas.
3. Usa **Simular lluvia** para activar o quitar la alerta de riesgo.
4. Revisa el panel de alerta y la gráfica antes de planear una ruta.

## Qué ves en pantalla
- El mapa muestra accidentes como calor y las zonas como polígonos de riesgo.
- La gráfica resume accidentes e intensidad acumulada por hora.
- La tarjeta de alerta cambia cuando la lluvia simulada está activa.

## Modo offline
Si no hay conexión, la PWA muestra `offline.html` y conserva recursos básicos instalados.
