# Manual de usuario

1. Abre la app y consulta el **Mapa de calor** para identificar zonas de mayor siniestralidad.
2. Revisa el panel de **Clima y alerta** antes de iniciar ruta.
3. Usa la gráfica de **Tendencia horaria** para evitar horas pico de accidentes y congestión.

## Modo offline
Si no hay conexión, la app muestra una vista offline y conserva recursos precargados de la PWA.
